# Lazy Musician Skills

A collection of opencode-compatible music theory skills for musicians, producers, and hobbyists.

## Skills

### [chords-progression-inference](.opencode/skills/chords-progression-inference/SKILL.md)
Decode and reverse-engineer guitar chord progressions when mid-range frequencies are muddy. Uses outer-voice isolation, harmonic interpolation, and ergonomic validation to figure out what chords are being played.

### [chords-arrangement-from-melody](.opencode/skills/chords-arrangement-from-melody/SKILL.md)
Derive a chord arrangement from a monophonic melody line. Covers structural tone analysis, harmonic rhythm estimation, chord assignment, voice leading, and genre-specific refinement.

## Usage

These skills are designed for [opencode](https://opencode.ai). Load them in your opencode session:

```
opencode --skill lazy-musician-skills/chords-progression-inference
opencode --skill lazy-musician-skills/chords-arrangement-from-melody
```
